# 项目归属标注与会话时间排序

本机 Intel 安装包：0.7.2b11+documents.7。

## 导出项目记录

会话 manifest 保持 format 4，新增 project_metadata_format 1。每条 sessions 记录的 project 包含项目分组 ID、原始项目 ID、名称、根目录、类型及识别依据；顶层 projects 汇总同一项目的 session_ids。项目以 ID 分组，不会仅因名字相同而合并。

优先读取 Codex 会话数据库的项目归属，并兼容 .codex-global-state.json 的旧项目定义、会话项目映射及旧 ID 到新 ID 的迁移映射。明确标为未归属项目的会话不会按工作目录强行归组。没有明确归属时按目录辅助标注，并显示“目录推断”；来源记录冲突时保留候选项目并标为“项目归属冲突”。

## 导入预览

左侧列表显示“标题／来源项目／最后活动”。默认按最后活动时间降序，点击时间表头切换升降序；时间未知的会话始终排在末尾。时间来自实际对话记录，不采用上传时间或文件修改时间，列表按北京时间显示。Task ID 保留在右侧详情中。

来源项目下拉框可筛选同项目会话，并显示数量。同名但不同 ID 的项目会区分显示。右侧详情显示项目名称、根目录及冲突信息。切换排序和项目筛选不会打乱会话与正文、标题编辑的对应关系。

## 保存与已有会话保护

正式导入时，只有新增会话的来源项目记录保存到 Codex 数据目录下 sync-project-membership.json。再导出时可保留这些原始归属；若用户后来给会话指定了本机项目，则明确的本机归属优先。该文件与新增会话一并参与备份和撤销。

来源项目标注用于同步软件展示和再次导出。本版不自动创建 Codex 项目或将会话分配进本机项目，也不更新已有会话的项目归属、标题、正文或工作目录。旧导出缺少原始归属时，只能显示目录推断或未知；用新版在原设备重新导出后才能携带明确归属。

## 验证

197 项自动测试通过，涵盖同项目不同工作目录、同名不同项目、数据库归属优先、旧项目 ID 迁移、明确无项目、目录边界、来源冲突、旧 manifest 兼容、再次导出、已有会话保护及撤销。实际 Tk 窗口验证了默认排序、表头切换、未知时间置后、选中会话保持、项目筛选及正文预览。安装包另行完成启动、导入预览、文档解析及 DMG 校验。未向真实本机 Codex 导入会话。
