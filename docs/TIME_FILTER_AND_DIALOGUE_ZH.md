# 时间筛选与对话预览

本机 Intel 版：0.7.2b11+documents.6。

在“同步与导入”页面选择“导入时间范围”：全部时间、最近 7／30／90／180／365 天，或自定义日期。自定义格式为 YYYY-MM-DD，可只填写开始或结束日期，结束日包含在范围内。最近 N 天包含今天，按本机时区的自然日计算。执行预览、导入或一键同步时保存选择，下次打开继续使用；升级默认全部时间。

筛选依据为同一会话所有仓库副本中最新的实际记录时间，不使用上传时间或文件修改时间。旧会话后来继续使用，仍能按新的活动时间进入范围。开启筛选后，无有效记录时间的会话会跳过。预览中的“按时间跳过”列出原因。

时间筛选仅控制仓库会话导入，不删除本机或仓库数据，不改变导出范围。已有同 ID 的本机会话始终保护，保留正文、标题、项目归属和工作目录。预览与正式导入使用相同的时间筛选逻辑，正式导入重新分析仓库。

导入预览默认采用“对话模式”：按“你／助手”分块展示消息与时间，保留换行，隐藏工具调用、工具输出、内部事件和分析记录；合并事件和消息记录中的重复镜像。图片以附件占位文字显示，不下载图片。可切换“完整记录”查看原有的日志文字预览。两种模式均只读，不更改会话文件。

验证：187 项测试通过，涵盖日期范围与时区、日期校验、跨设备最新活动时间、缺失时间、原有会话保护、对话角色、重复镜像、日志隐藏与完整记录切换。Tk 实际窗口检查通过，验证日期输入、角色样式、只读状态、模式切换及关闭按钮可见；使用示例对话实际截图检查布局。安装包另行进行启动、导入预览、文档解析及 DMG 校验。
