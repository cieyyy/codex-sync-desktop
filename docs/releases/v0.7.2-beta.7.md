# Codex Sync Desktop v0.7.2 Beta 7

Beta 7 重点修复全新设备连接已有私有仓库后的会话恢复流程，并完成面向公开仓库的项目说明。

## 主要变化

- 新电脑没有 `.codex/sessions`、但 GitHub 仓库已有其他设备数据时，完成连接后直接引导选择来源设备导入。
- 没有本地和远端会话时，明确提示先完成一次 Codex 对话，不再显示英文目录错误。
- 修复 Git 在 Windows/macOS 间转换换行符导致整批 JSONL SHA-256 校验失败。
- 设备名称支持 Unicode；旧版 `device` 目录在 manifest 确认属于当前设备后安全迁移。
- 来源设备列表和预览窗口显示 manifest 中的真实设备名称。
- 误选 GitHub ZIP 解压目录时保留原快照，并在同级目录自动创建正式 Git 克隆。
- 移除主界面的“查看解决办法”和设置页“初始化/克隆仓库”入口，仓库连接统一由首次配置向导完成。
- 安全确认未勾选时，下一步会提示、自动勾选并继续。
- 界面明确标注：拉取、导出、预览无需退出；导入修复、含导入的一键同步和撤销前必须退出 ChatGPT/Codex/Codex++。
- README 按开源项目重新组织，新增英文说明、贡献指南、安全策略和行为准则。

## 验证

- 自动测试：133 项通过。
- Python `compileall`：通过。
- `git diff --check`：通过。
- 实际 ZIP 快照验证：445 个 JSONL；“天文”来源预演新增 444、哈希失败 0。

## 安全提示

应用源码公开不代表会话数据可以公开。同步仓库必须保持私有；会话正文中的 Token、密钥、密码、连接串、命令、工具输出和推理文字会被保留。

Windows 安装包尚无商业代码签名。安装前请核对 Release 中的 `SHA256SUMS.txt`。
