# v1.0.1 正式版

主题选择替换为太阳和月亮图标按钮，去掉下拉框与“外观”文字。

- 点击太阳切换浅色，点击月亮切换深色；选中主题以青色高亮。
- 记住本机主题偏好，切换时保留预览、筛选与未保存标题。
- 鼠标悬停显示模式提示；支持 Tab、空格和左右方向键操作。
- 使用正式绘制的抗锯齿图标，不依赖系统表情符号。
