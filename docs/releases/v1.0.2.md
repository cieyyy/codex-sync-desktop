# v1.0.2：退出相关进程与系统代理

同步页底部增加“一键退出相关进程”。点击后确认退出 Codex、ChatGPT、Codex++ 与关联辅助进程，先发送退出请求，3 秒后清理残留进程。按 PID 和可执行文件重新校验，仅处理识别到的相关程序，排除本同步软件。结束后重新检测；不自动执行导入、撤销或推送。

被后台进程阻挡的导入与撤销使用同一确认入口，避免显示大量完整路径。未保存内容及正在生成的回复可能因退出中断。

代理地址留空时，Git、GitHub CLI 与 Python HTTP 下载统一读取系统 HTTP/HTTPS 代理。手动代理覆盖系统配置，环境变量代理保留命令行覆盖规则。每次发起命令或请求时重新读取系统设置，不把自动检测地址固定保存。代理软件需开启系统代理，无需把 TUN 作为本软件的代理接入方式。PAC 自动配置与仅 SOCKS 的设置尚未纳入本次系统代理支持，可使用手动 HTTP/HTTPS 代理。

拉取错误现在明确区分未完成的 rebase 与分离 HEAD。遇到 rebase 时停止再次拉取，不自动切换分支或丢弃更改。当前同步数据仓库需先完成或中止已有 rebase，才能正常重新检查。

验证：212 项自动化测试通过；真实 Tk 界面覆盖深浅色和 920×640 最小窗口，进程操作使用模拟测试，没有关闭真实 Codex/ChatGPT 或导入真实会话。通过系统代理完成 Git 远端引用读取及 GitHub 网络探测；未执行真实上传，也未切换本机 TUN 设置。

本机安装包：dist/Codex-Sync-Desktop-v1.0.2-macOS-Intel.dmg。已验证 Intel 架构、1.0.2 版本、ad hoc 签名、应用/向导/预览启动、文档提取、DMG 和 SHA-256。退出旧版同步软件后安装新版。
