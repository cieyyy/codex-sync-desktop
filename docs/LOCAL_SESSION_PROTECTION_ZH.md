# 本机会话保护：仅导入缺少的会话

版本：0.7.2b11+documents.5，本机 Intel macOS 安装包。

同步和导入按会话 ID 判断本机是否已有记录，同时检查活动文件、嵌套文件、压缩归档、会话数据库、侧栏索引及本地会话目录。只要任一位置已有该 ID，就标记为“已保护本机会话”，不合并正文，不覆盖标题、工作目录或项目归属，也不能在导入预览中为它改名。

对本机缺少的 ID，先合并仓库中不同设备保存的记录，再新增会话文件。侧栏登记只插入新增行，原有数据库行不更新，原有 session_index.jsonl 字节保留后追加新条目。同步过程不再调用全量索引修复，不修改项目、置顶和排序配置。新会话保留源记录的工作目录，其在侧栏的分组仍由 Codex 解释该目录；不会为已有会话重新分配项目。

如果预览后本机出现同 ID 会话，正式导入会停止并要求重新预览，避免覆盖。重复导入全部跳过；无新增时不创建导入撤销点。校验失败会阻止导入。

验证：177 项自动测试通过，包含正文不变、原数据库全字段及自定义 project_id 不变、本地目录全字段不变、原索引字节保留、压缩归档与仅索引记录保护、重复导入、预览过期保护、撤销新增。安装包通过界面启动、导入预览、文档解析和 DMG 校验。真实本机仅执行只读规划，未执行导入；未进行真实 Codex 侧栏的导入集成测试。
