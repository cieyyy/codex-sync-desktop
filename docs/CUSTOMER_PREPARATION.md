# 购买用户首次使用准备清单

这份清单可直接发送给 Windows 或 macOS 用户。全程不需要输入 Git 命令。

## 下载前准备

请准备：

1. 已安装并启动过至少一次 Codex。
2. 一个能接收验证邮件的邮箱；没有 GitHub 账号也可以，软件内提供官方注册入口。
3. 能访问 GitHub 的网络。
4. 中国大陆或受限网络用户：提前准备符合所在地法律法规和单位规定的代理工具，并找到它显示的本机 **HTTP 代理地址**，常见形式为 `http://127.0.0.1:端口`。

不要把代理账号、密码发给销售方或客服。软件也不会接受包含账号密码的代理 URL。

## 应下载哪个文件

- Windows 普通用户：`Codex-Sync-Desktop-Windows-Setup.exe`
- Windows 便携使用：`Codex-Sync-Desktop-Windows.zip`
- Apple 芯片 Mac（M1/M2/M3/M4 等）：`macOS-Apple-Silicon.dmg`
- Intel 芯片 Mac：`macOS-Intel.dmg`

只从正式销售下载页或项目 Release 下载，并用同一 Release 中的 `SHA256SUMS.txt` 核对文件。

## 第一次打开后

按照四步向导操作：

1. 确认私有仓库和敏感文字提示。
2. 测试 GitHub 网络；需要代理时填写本机 HTTP 代理。
3. 注册或登录 GitHub；缺少必要工具时点击“自动安装/修复必要工具”。
4. 点击“创建仓库并首次同步”，等待显示“首次配置全部完成”。

软件会自动创建仅当前 GitHub 账号可见的私有仓库。不要把仓库改成公开，也不要邀请不可信协作者。

## 换到新设备

在新设备安装软件，登录同一个 GitHub 账号，运行首次配置向导并连接同名私有仓库。选择来源设备后使用“一键同步”；需要导入时，先完全退出 Codex、ChatGPT 和 Codex++。

## 需要人工完成的安全步骤

以下步骤不能由软件代替：

- 邮箱验证、密码、验证码和双因素认证。
- GitHub 浏览器设备授权确认。
- Windows/macOS 系统安装器的管理员授权。
- 代理工具的购买、安装、启动及合规使用。
