# Codex Sync Desktop 小白首次配置手册

## 开始前准备

需要准备：

1. 已经安装并至少启动过一次 Codex。
2. 一个可以接收验证邮件的邮箱。
3. 可以访问 GitHub 的网络。
4. 不需要提前手动安装 Git 或 GitHub CLI。向导会实际启动检测并自动安装；Windows 的 winget 不可用或失败时自动下载、校验官方 EXE/MSI，macOS 自动打开系统命令行工具安装器和经过 SHA-256 校验的官方 universal.pkg。用户只需确认系统安装授权。

同步记录可能包含命令、工具输出、Token、密钥或连接串。软件只允许自动创建并连接 GitHub 私有仓库，不要把仓库改成公开。

## 四步配置

### 第一步：隐私确认

阅读上传范围并勾选确认。软件不会上传图片、附件二进制、归档会话和已删除会话。

### 第二步：网络与中国大陆提示

普通网络直接点击“测试 GitHub 连接”。

中国大陆用户如果无法连接：

1. 先启动符合所在地法律法规以及所在组织规定的网络代理工具。
2. 在代理工具中查看“HTTP 代理”本机地址和端口。
3. 在向导中填写，例如：`http://127.0.0.1:7890`。
4. 点击“测试 GitHub 连接”。只有显示连接成功后才能继续；测试成功的代理设置会立即保存，中途关闭软件也不必重新填写。

软件拒绝保存带账号密码的代理 URL，避免凭据以明文写入配置文件。

### 第三步：GitHub 账号和登录

- 没有账号：点击“没有账号：打开注册”，在 GitHub 页面完成邮箱验证。
- 已有账号：点击“打开 GitHub 登录”，根据终端和浏览器提示授权设备。
- 系统安装完成后软件会自动复检；三个检查项都显示“已完成”后继续。

GitHub 官方设备授权要求用户在浏览器确认一次，软件不能代替用户注册账号、输入密码、验证码或双因素认证。

### 第四步：创建私有仓库并首次同步

默认仓库名为 `codex-sync-vault`。点击“创建仓库并首次同步”后，软件会：

1. 读取当前登录的 GitHub 账号。
2. 创建私有仓库，或连接同名且已经存在的私有仓库。
3. 再次检查仓库确实为私有。
4. 克隆仓库到本机。
5. 配置本仓库的 Git 用户名和隐私邮箱。
6. 保存 Codex 数据目录、设备名称、仓库地址和代理设置。
7. 导出本机活动文字会话，提交并推送到新建的私有仓库。

如果检测到同名公开仓库，软件会拒绝继续。只有首次推送成功后才会显示“首次配置全部完成”；网络中断时配置会保留，可在最后一步直接重试。

## 日常使用

最简单方式是使用“一键同步”：

- 没有选择其他来源设备：拉取仓库后上传本机活动会话。
- 已选择其他来源设备：拉取、导入合并、修复侧栏，再上传本机活动会话。

一键同步包含导入时，必须先完全退出 Codex、ChatGPT 和 Codex++。

也可以按传统方式操作。离开当前设备前点击“导出并推送”。

换到其他设备后：

1. 点击“拉取仓库”。
2. 选择来源设备并点击“预览导入”。
3. 完全退出 Codex、ChatGPT 和 Codex++。
4. 点击“导入并修复”。
